# Repository contents

The repository implements the PILAR experiments and analyses used in the paper.

| Location | Purpose |
|---|---|
| `lipnet/` | PILAR operators, inhibition, training, inference, metrics, data handling, and cost accounting |
| `scripts/reproduce_paper.py` | Fixed MVTec, VisA, and MVTec component-ablation protocols |
| `scripts/` | Complementary image/RGB experiments and inference/timing tools |
| `configs/` | Fixed model and experiment configurations |
| `analysis/` | Reference validation, review-budget curves, and subtype analysis |
| `results/reference/paper/` | Complete paper category/seed metrics, image scores, and seed-level summaries |
| `results/reference/` | Complementary strict-image and RGB control results |
| `tests/` | Offline tests of model, metric, checkpoint, and protocol behavior |

MVTec AD, VisA, MNIST, Fashion-MNIST, CIFAR-10, and pretrained ImageNet weights
remain subject to their original distribution terms. Dataset images and
trained checkpoints are not bundled. The supplied training commands generate
models, prediction records, and evaluation artifacts from the fixed protocols.

Literature baseline numbers are not generated by this implementation. The
repository does not include third-party baseline training or research extensions.
Public reference provenance uses repository-relative logical source names
and hashes; execution logs generated on a user's machine describe that user's
own environment and paths.
